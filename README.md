# 🌌 Meu Portfólio (Linktree Style)

Este projeto é uma central de links personalizada, desenvolvida para reunir minhas redes profissionais e projetos em um só lugar. Ele conta com um fundo dinâmico de partículas para criar uma experiência visual moderna e interativa.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estrutura semântica do conteúdo. 🧱
* **CSS3**: Estilização com foco em dispositivos móveis (**Mobile First**) e efeitos de transparência. 🎨
* **JavaScript (Canvas API)**: Sistema de partículas animadas que reagem ao tamanho da tela. ⚡

## 📚 O que aprendi

Durante o desenvolvimento deste projeto, pude colocar em prática e aprofundar meus conhecimentos em:
* **Deploy e Git**: Como publicar um site gratuitamente e torná-lo acessível ao mundo usando o **GitHub Pages**. 🌍
* **CSS para Dispositivos Móveis**: A importância da unidade `dvh` (Dynamic Viewport Height) e de áreas de clique (*Touch Targets*) para criar uma verdadeira experiência de aplicativo. 📱
* **Lógica Matemática no Código**: O uso da API do Canvas para desenhar formas e o cálculo de distância entre pontos (usando o Teorema de Pitágoras) para conectar as constelações. 📐
* **Otimização de Algoritmos**: Como melhorar a performance de laços de repetição (*loops* aninhados) na verificação de colisão e distância das partículas. 🚀

## 🛠️ Funcionalidades

* **Design Responsivo**: Adaptado para celulares e desktops.
* **Fundo Animado**: Constelações geradas via código que se ajustam ao redimensionar a janela.
* **Interface Limpa**: Foco total na facilidade de acesso aos links.
